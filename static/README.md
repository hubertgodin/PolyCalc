# Static

Ce dossier contient les fichiers statiques de l’application (CSS, images, JS).

## Raison d’être
Assurer la mise en forme et le style visuel de l’application PolyCalc.

## Fichiers principaux
- `style.css` : feuille de style principale utilisée par `index.html`.

## Dépendances / hypothèses
- Les fichiers statiques sont servis automatiquement par Flask via la route `/static/...`.
